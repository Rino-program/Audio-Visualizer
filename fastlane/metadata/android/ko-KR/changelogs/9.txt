v1.0.9의 업데이트 내용은 다음과 같습니다.

- 디스플레이 환경(white-space: pre-wrap 등)으로 인한 의도치 않은 줄 간격 벌어짐(불필요한 공백)을 해결하고, 각 요소의 마진을 최적화했습니다.
- 발광 강도 번역 누락을 수정했습니다.
- 초기 릴리스 및 베타 버전 배포에 관한 설명을 추가했습니다.
- UI 전환 버튼의 아이콘 크기를 2048x2048에서 360x360으로 변경했습니다.
- 탭 조작 시 UI 전환 버튼 반응과 UI 자동 숨김 판정이 중복되어 UI 표시 전환이 불안정해지던 문제를 수정했습니다.
- 동영상 창 위치를 px가 아닌 화면 크기 비율로 저장하고 화면 회전/크기 변경 시 뷰포트 내로 재배치하여, 가로/세로 전환 시 UI나 동영상이 좌상단으로 쏠리던 문제를 수정했습니다.(실기기 검증 전)
