# v1.1.4 Changelog

## Third-party licenses

- Organized third-party license information for npm, Android/Gradle, fonts, and image assets.
- Clearly separated the application's MIT License from third-party component licenses.
- Bundled the application's MIT License text in the APK.
- Bundled the MIT, Apache License 2.0, 0BSD, and SIL Open Font License 1.1 texts.
- Recorded copyright and font license information for Inter and Roboto Mono.
- Documented the confirmed provenance information for images and icons without inventing unidentified copyright holders.
- Added access to the bundled third-party license texts from the Developer tab in the app.

## License checks

- Added Licensee 1.14.1 for Android Gradle dependency license validation.
- Android license validation now fails for licenses that are not allowed or cannot be identified.
- Configured the Licensee dependency report to be bundled in Android build artifacts.
- Added `license-report-recursive` to inspect production npm dependencies and their transitive dependencies.
- Added `npm run licenses:check` to run the npm and Android license checks together.

## Documentation

- Documented the third-party license investigation and user-facing license document locations in the README.
- Documented the license check commands and report locations in the README.
