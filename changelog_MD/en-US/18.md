# v1.1.5 Changelog

## Rendering

- Removed the "Rendering Mode (Auto / GPU Priority / CPU)" setting.
- Rendering was always performed with Canvas2D, and there was no GPU/CPU switching feature. The app now truthfully displays "Rendering Backend: Canvas2D".
- Changed the resource monitor's "GPU / CPU" indicator to "Canvas2D".
- Rendering mode values saved by older versions are now removed automatically when settings and presets are loaded.

## Localization

- Added Korean (ko-KR) support, including the UI, in-app messages, Fastlane metadata, and changelogs.
- Added Japanese, English, Simplified Chinese, and Korean versions of README and SECURITY.

## Documentation

- Updated the security policy's supported version to v1.1.5 and later.

## Other

- Reformatted the entire codebase with Prettier.
