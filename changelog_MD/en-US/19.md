# v1.2.0 Changelog

## Rendering

- Added an "Internal Resolution" setting with Power Saving (1.0x), Standard (1.5x), High Quality (2.0x), Maximum (2.5x), and Native options.
- Bar, waveform, and particle sizes are compensated so the visuals keep the same apparent size when the internal resolution changes.
- Internal resolution is now adjusted automatically based on rendering load. It can drop to as low as 0.6x on slower devices and recovers gradually when there is headroom.
- Glow is now generated as a bloom pass from a dedicated visualizer layer that excludes the background. It stays visible even with many bars and no longer washes out the background.
- Glow is now available in low-FPS mode.

## Performance

- The render loop now runs only while playing or using microphone input, and stops while playback is paused. Settings changes and seeks redraw only the frames they need.
- Rendering stops completely when the app goes to the background and resumes when it returns.
- The frosted-glass blur on the top bar and control panels is disabled during playback to remove per-frame compositing cost.
- Draft edits in the settings screen no longer trigger unnecessary redraws.
- Time-domain waveform data is now fetched only in waveform mode.
- Reduced drawing cost by reusing spectrum buffers, precomputing rainbow colors (LUT), decimating waveform points, batching digital-block drawing, and sharing transform calculations in circle mode.

## Playback

- Added bulk import from the device music library (MediaStore).
- Reads title, artist, album, and album art and shows them in the now-playing view and notification.
- Added a foreground service for background playback, with notification, lock-screen, and headset media controls.
- Added audio focus handling to pause when another app starts playback.
- Saves the last track and position and restores them on the next launch.
- Added a "Keep the screen awake" setting.
- Requests notification (Android 13+) and music library permissions when needed.

## Settings

- Changes in the settings screen are now kept as a draft and applied only when "Save & Close" is pressed. Closing without saving discards them.
- Closing with unsaved changes now asks for confirmation before discarding them.
- Language, microphone, equalizer, playback speed, and other settings are applied together on save.

## Fixes

- Fixed bars and monitor bars looking thinner and circle sand particles looking larger when the internal resolution was lowered.
- Fixed glow doing nothing when it was enabled with strength 0; enabling it now sets strength to 20.
- Fixed an issue where selecting "Unlimited (MAX)" for FPS displayed 60 FPS after reopening the settings screen.
- Fixed the FFT quality preset overwriting the saved bar count.
- Keyboard shortcuts no longer change settings while the settings screen is open.
- Fixed default browser borders appearing on the settings tabs.
- Fixed the Glow strength label not updating after changes or when reopening settings.
- Fixed the F key not working despite the "Fullscreen (F)" label, and added the shortcut to Help.
- Fixed the settings screen retaining its previous scroll position when reopened.
- Fixed the settings screen becoming extremely narrow in landscape and made it full-screen.
- Fixed the Android back button exiting the app instead of closing settings or the playlist.
- Fixed the landscape top bar stretching vertically and the mode selector falling onto its own row.
- Fixed the "Presets" and "Storage" tabs not appearing in settings, which made color presets and stored-file management inaccessible. The tab bar now stays on one row and scrolls horizontally on narrow screens.
- Fixed the top and bottom bars becoming too tall on tablets and wide screens; they now use a single-row layout at 600px and above. Padding on phones has also been reduced.
- The playlist is now always anchored below the top bar, with its height and position adjusted automatically so it never overlaps the playback controls.
- Filled in missing translation keys and replaced hardcoded Japanese text so all four languages show the same screens.
- Fixed translation files being loaded twice at startup.
- Improved microphone error handling so an error message containing "Permission" is no longer treated as a denied permission by itself.

## Other

- Added UI strings for internal resolution and the unsaved-changes confirmation in Japanese, English, Simplified Chinese, and Korean.
- Moved the UI visibility toggle into the top bar and now show a floating "Show UI" button only while the UI is hidden.
- Added Glow strength labels (Weak/Medium/Strong) and the "Show UI" strings in Japanese, English, Simplified Chinese, and Korean.
- Unified the version display to v1.2.0 (version code 19).
- Added a "Text and UI size" setting that scales the entire interface except the visualizer from 80% to 130%.
- Merged the video visibility and video mode settings into one three-way choice: Audio only / Window / Background.
