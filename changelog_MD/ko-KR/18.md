# v1.1.5 변경 내역

## 렌더링

- 설정의 "렌더링 모드(자동 / GPU 우선 / CPU)"를 삭제했습니다.
- 실제 렌더링은 항상 Canvas2D를 사용했으며 GPU/CPU 전환 기능은 없었습니다. 이제 실제 상태에 맞게 "렌더링 백엔드: Canvas2D"로 표시합니다.
- 리소스 모니터의 "GPU / CPU" 표시를 "Canvas2D"로 변경했습니다.
- 이전 버전에서 저장된 렌더링 모드 설정은 설정 및 프리셋을 불러올 때 자동으로 삭제됩니다.

## 언어 지원

- 한국어(ko-KR)를 지원합니다. UI, 앱 내 메시지, Fastlane 메타데이터, 변경 내역을 추가했습니다.
- README와 SECURITY를 일본어, 영어, 중국어 간체, 한국어로 정비했습니다.

## 문서

- 보안 정책의 지원 버전을 v1.1.5 이상으로 업데이트했습니다.

## 기타

- Prettier로 전체 코드를 정리했습니다.
