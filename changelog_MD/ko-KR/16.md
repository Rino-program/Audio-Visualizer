# v1.1.3 변경 내역

## Android 및 Capacitor 기반

- Capacitor CLI, Core, Android를 8.5.3으로 업데이트했습니다.
- Android 최소 SDK를 24, compile SDK 및 target SDK를 36으로 업데이트했습니다.
- Capacitor 8에 맞춰 AndroidX Activity, Core, Fragment, WebKit 등의 종속성 버전을 업데이트했습니다.
- Android 빌드를 Java 21에서 실행할 수 있도록 설정을 정리했습니다.
- Node.js 22 이상, JDK 21을 필수 빌드 환경으로 명시했습니다.
- Git에서 Gradle wrapper의 실행 권한을 설정했습니다.
- npm 종속성을 업데이트하여 `npm audit`의 취약점을 해결했습니다.

## 파일 가져오기

- Android 폴더 가져오기를 전용 백그라운드 Executor에서 실행하도록 개선했습니다.
- 대량의 파일이 포함된 폴더를 가져오더라도 공유 작업 큐를 장시간 점유하지 않도록 했습니다.
- Activity 재생성이나 소멸이 발생하더라도 미전달된 가져오기 결과를 앱 내부에 저장하여 복원할 수 있도록 했습니다.
- 가져오기 결과를 재생목록에 저장한 후 확인 응답(ACK)을 수행하여, 저장 실패 시 파일 참조를 잃지 않도록 했습니다.
- 보류 중인 가져오기 결과가 있을 때 새 가져오기로 덮어쓰지 않도록 방지했습니다.
- 보류 결과 저장에 실패한 경우 이번 작업으로 생성된 파일만 안전하게 정리하도록 했습니다.
- 가져온 파일 삭제 시 앱의 가져오기 디렉터리 외부로 접근하지 않도록 격리했습니다.
- 여러 번의 가져오기 및 삭제 작업이 서로 충돌하지 않도록 큐를 관리했습니다.

## 보안 및 안정성

- 재생목록, 저장소 목록, 마이크 기기 목록의 DOM 생성을 안전화했습니다.
- 사용자가 선택한 파일명이나 경로가 HTML로 해석되지 않도록 처리했습니다.
- 설정 및 재생목록 저장 실패를 감지하여 설정 창을 닫지 않고 사용자에게 알리도록 개선했습니다.
- 복원 처리에 실패하더라도 앱 초기화가 중단되지 않고 지속되도록 했습니다.
- Capacitor 8의 `registerPlugin`을 사용하여 네이티브 플러그인을 가져오도록 변경했습니다.
- 폴더 선택 플러그인의 Activity 결과 코드를 등록했습니다.

## CI 및 문서

- GitHub Actions 권한을 정리하고 불필요한 권한을 최소화했습니다.
- PR Agent Action을 커밋 SHA로 고정했습니다.
- Android 빌드 절차, 서명 설정, 미서명 APK 취급 방침을 README에 추가했습니다.
- `keystore.properties` 설정 예시와 `storeFile` 기준 경로를 README에 추가했습니다.
- Android debug/release APK 빌드 절차를 정리했습니다.
