# v1.2.0 변경 내역

## 렌더링

- 설정에 "내부 해상도"를 추가했습니다. 절전(1.0x), 표준(1.5x), 고화질(2.0x), 최고(2.5x), 네이티브 중에서 선택할 수 있습니다.
- 내부 해상도를 변경해도 바, 파형, 입자 등의 크기가 같아 보이도록 보정합니다.
- 렌더링 부하에 따라 내부 해상도를 자동으로 조정합니다. 느린 기기에서는 최대 0.6배까지 낮아지고, 여유가 생기면 단계적으로 복구됩니다.
- 글로우를 배경을 포함하지 않는 시각화 레이어에서 생성하는 블룸 합성으로 변경했습니다. 바 개수가 많아도 빛이 잘 보이고 배경이 하얗게 뜨지 않습니다.
- 저 FPS 모드에서도 글로우를 사용할 수 있습니다.

## 성능

- 재생 중이거나 마이크 입력 중일 때만 렌더 루프를 실행하고, 정지 상태에서는 그리기를 멈춥니다. 설정 변경이나 탐색 시에는 필요한 프레임만 다시 그립니다.
- 앱이 백그라운드로 이동하면 렌더 루프를 완전히 멈추고, 돌아오면 다시 시작합니다.
- 재생 중에는 상단 바와 조작 패널의 반투명 유리 효과(배경 블러)를 중지해 매 프레임 합성 부하를 줄였습니다.
- 설정 화면의 초안 변경 시 불필요한 다시 그리기를 하지 않도록 했습니다.
- 시간 파형 데이터는 파형 모드에서만 가져오도록 했습니다.
- 스펙트럼 버퍼 재사용, 레인보우 색상 사전 계산(LUT), 파형 샘플 생략, 디지털 블록 일괄 그리기, 원형 모드 변환 행렬 공유 등으로 그리기 비용을 줄였습니다.

## 재생

- 기기 음악 라이브러리(MediaStore)에서 곡을 한꺼번에 가져올 수 있습니다.
- 제목, 아티스트, 앨범, 앨범 아트를 읽어 재생 화면과 알림에 표시합니다.
- 백그라운드 재생을 위한 포그라운드 서비스를 추가하고 알림, 잠금 화면, 헤드셋 미디어 조작을 지원합니다.
- 오디오 포커스를 지원해 다른 앱이 재생을 시작하면 일시 정지합니다.
- 마지막 곡과 재생 위치를 저장하고 다음 실행 시 이어서 재생합니다.
- "화면 켜짐 유지" 설정을 추가했습니다.
- 필요할 때 알림(Android 13+) 및 음악 라이브러리 권한을 요청합니다.

## 설정

- 설정 화면의 변경 사항을 임시 초안으로 보관하고 "저장 후 닫기"를 눌렀을 때만 적용합니다. 저장하지 않고 닫으면 변경 사항이 취소됩니다.
- 저장하지 않고 닫으려 할 때 변경 사항을 버릴지 확인합니다.
- 언어, 마이크, 이퀄라이저, 재생 속도 등의 설정도 저장 시 한꺼번에 적용됩니다.

## 수정

- 내부 해상도를 낮췄을 때 바와 모니터 바가 얇아 보이고 원형 모드의 모래 입자가 커 보이던 문제를 수정했습니다.
- 글로우를 켜도 강도가 0이면 아무것도 표시되지 않던 문제를 수정하고, 켤 때 강도를 20으로 설정하도록 했습니다.
- FPS에서 "무제한 (MAX)"을 선택한 뒤 설정 화면을 다시 열면 60 FPS로 표시되던 문제를 수정했습니다.
- FFT 품질 프리셋이 저장된 "바 개수"를 덮어쓰던 문제를 수정했습니다.
- 설정 화면이 열려 있는 동안에는 키보드 단축키로 설정이 변경되지 않습니다.
- 설정 탭에 브라우저 기본 흰색 테두리가 표시되던 문제를 수정했습니다.
- Glow 강도 표시가 변경 후 또는 설정을 다시 열 때 갱신되지 않던 문제를 수정했습니다.
- "전체 화면 (F)"로 표시되지만 F 키가 동작하지 않던 문제를 수정하고 도움말에 추가했습니다.
- 설정 화면을 다시 열 때 이전 스크롤 위치가 남던 문제를 수정했습니다.
- 가로 화면에서 설정 화면이 지나치게 좁아지던 문제를 수정하고 전체 화면으로 표시하도록 변경했습니다.
- Android 뒤로 가기 버튼으로 설정 화면이나 재생 목록이 닫히지 않고 앱이 종료되던 문제를 수정했습니다.
- 가로 화면에서 상단 바가 세로로 길어지고 모드 선택만 별도 줄로 내려가던 문제를 수정했습니다.
- 설정의 "프리셋" 및 "저장소" 탭이 표시되지 않아 색상 프리셋과 저장 파일 관리를 열 수 없던 문제를 수정했습니다. 탭 표시줄은 한 줄로 유지되고 좁은 화면에서는 가로로 스크롤할 수 있습니다.
- 태블릿과 가로 화면에서 상단·하단 바가 세로로 커지던 문제를 수정하고 600px 이상에서는 한 줄 레이아웃으로 정리했습니다. 스마트폰에서도 여백을 줄였습니다.
- 재생목록을 항상 상단 바 아래에 표시하고, 하단 재생 컨트롤을 가리지 않도록 높이와 위치를 자동 조정합니다.
- 누락된 번역 키를 채우고 하드코딩된 일본어를 제거해 네 언어에서 동일한 화면이 표시되도록 했습니다.
- 시작 시 번역 파일을 두 번 불러오던 문제를 수정했습니다.
- 오류 메시지에 "Permission"이 포함된다는 이유만으로 마이크 권한 거부로 표시되던 문제를 개선했습니다.

## 기타

- 내부 해상도와 저장하지 않은 변경 확인 UI 문구를 일본어, 영어, 중국어 간체, 한국어에 추가했습니다.
- UI 표시 전환 버튼을 상단 바 안으로 옮기고, UI가 숨겨진 동안에만 플로팅 "UI 표시" 버튼을 표시하도록 변경했습니다.
- Glow 강도 표시(약/중/강)와 "UI 표시" 문구를 일본어, 영어, 중국어 간체, 한국어에 추가했습니다.
- 버전 표시를 v1.2.0(버전 코드 19)으로 통일했습니다.
- "글자 및 UI 크기" 설정을 추가했습니다. 80~130% 범위에서 비주얼라이저를 제외한 전체 UI 크기를 조정할 수 있습니다.
- 동영상의 "표시/숨김"과 "표시 모드"를 하나의 설정으로 통합해 "오디오만 / 창 / 배경" 중에서 선택할 수 있습니다.
