# v1.1.6 변경 내역

## 렌더링

- 설정에 "내부 해상도"를 추가했습니다. 절전(1.0x), 표준(1.5x), 고화질(2.0x), 최고(2.5x), 네이티브 중에서 선택할 수 있습니다.
- 내부 해상도를 변경해도 바, 파형, 입자 등의 크기가 같아 보이도록 보정합니다.
- 렌더링 부하에 따라 내부 해상도를 자동으로 조정합니다. 느린 기기에서는 최대 0.6배까지 낮아지고, 여유가 생기면 단계적으로 복구됩니다.
- 바마다 shadowBlur를 사용하던 글로우를 저해상도 블룸 합성으로 변경해 부하를 크게 줄였습니다.
- 저 FPS 모드에서도 글로우를 사용할 수 있습니다.

## 성능

- 재생 중이거나 마이크 입력 중일 때만 렌더 루프를 실행하고, 정지 상태에서는 그리기를 멈춥니다. 설정 변경이나 탐색 시에는 필요한 프레임만 다시 그립니다.
- 앱이 백그라운드로 이동하면 렌더 루프를 완전히 멈추고, 돌아오면 다시 시작합니다.
- 스펙트럼 버퍼 재사용, 레인보우 색상 사전 계산(LUT), 파형 샘플 생략, 디지털 블록 일괄 그리기, 원형 모드 변환 행렬 공유 등으로 그리기 비용을 줄였습니다.

## 설정

- 설정 화면의 변경 사항을 임시 초안으로 보관하고 "저장 후 닫기"를 눌렀을 때만 적용합니다. 저장하지 않고 닫으면 변경 사항이 취소됩니다.
- 언어, 마이크, 이퀄라이저, 재생 속도 등의 설정도 저장 시 한꺼번에 적용됩니다.

## 수정

- FPS에서 "무제한 (MAX)"을 선택한 뒤 설정 화면을 다시 열면 60 FPS로 표시되던 문제를 수정했습니다.
- 설정 화면이 열려 있는 동안에는 키보드 단축키로 설정이 변경되지 않습니다.

## 기타

- 내부 해상도 UI 문구를 일본어, 영어, 중국어 간체, 한국어에 추가했습니다.
