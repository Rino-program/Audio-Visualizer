# v1.1.4 변경 내역

## 타사 라이선스

- npm, Android/Gradle, 폰트, 이미지 소재의 타사 라이선스 정보를 체계적으로 정리했습니다.
- 앱 본체의 MIT 라이선스와 타사 컴포넌트 라이선스를 명확히 분리했습니다.
- 앱 본체의 MIT 라이선스 전문을 APK 내부에도 동봉했습니다.
- MIT, Apache License 2.0, 0BSD, SIL Open Font License 1.1 라이선스 전문을 동봉했습니다.
- Inter 및 Roboto Mono의 저작권 표기 및 폰트 라이선스 정보를 기록했습니다.
- 이미지 및 아이콘에 대해 확인된 생성 출처 정보를 기록하고, 확인되지 않은 저작권자를 임의로 추정하여 기재하지 않는 방침을 명시했습니다.
- 앱 내 '개발자 정보' 탭에서 타사 라이선스 전문을 확인할 수 있도록 지원했습니다.

## 라이선스 검사

- Android Gradle 종속성 검사를 위해 Licensee 1.14.1을 도입했습니다.
- 허용되지 않았거나 식별할 수 없는 Android 종속성 라이선스가 있는 경우 검사가 실패하도록 구성했습니다.
- Licensee 종속성 리포트를 Android 빌드 산출물에 포함하도록 설정을 추가했습니다.
- npm 프로덕션 종속성 및 전이 종속성을 분석하는 `license-report-recursive`를 도입했습니다.
- `npm run licenses:check` 명령어로 npm과 Android 라이선스 검사를 함께 실행할 수 있도록 지원했습니다.

## 문서

- 저장소 루트에 [THIRD_PARTY_LICENSES.md](../../THIRD_PARTY_LICENSES.md)를 추가했습니다.
- README에 타사 라이선스 확인 절차, 검사 명령어, 수동 확인 방침을 추가했습니다.
- APK 내 동봉 라이선스 배치 경로를 README와 변경 내역에 명시했습니다.
