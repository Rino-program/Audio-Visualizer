# v1.1.5 変更履歴

## 描画

- 設定の「レンダリングモード（自動 / GPU優先 / CPU）」を削除しました。
- 実際の描画は Canvas2D で行われており、GPU/CPU を切り替える機能はありませんでした。実態に合わせて「描画バックエンド: Canvas2D」と表示するようにしました。
- リソースモニターの「GPU / CPU」表示を「Canvas2D」に変更しました。
- 旧バージョンで保存された描画モード設定は、設定読み込み時とプリセット読み込み時に自動的に削除されます。

## 言語対応

- 韓国語（ko-KR）に対応しました。UI、アプリ内メッセージ、Fastlane メタデータ、変更履歴を追加しています。
- README と SECURITY を日本語・英語・簡体字中国語・韓国語で整備しました。

## ドキュメント

- セキュリティポリシーのサポート対象バージョンを v1.1.5 以降に更新しました。

## その他

- コード全体を Prettier で整形しました。
