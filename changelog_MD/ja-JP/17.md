# v1.1.4 変更履歴

## 第三者ライセンス

- npm、Android/Gradle、フォント、画像素材の第三者ライセンス情報を整理しました。
- アプリ本体のMITライセンスと第三者コンポーネントのライセンスを明確に分離しました。
- アプリ本体のMITライセンス本文をAPKにも同梱しました。
- MIT、Apache License 2.0、0BSD、SIL Open Font License 1.1のライセンス本文を同梱しました。
- InterとRoboto Monoの著作権表示およびフォントライセンス情報を記録しました。
- 画像・アイコンについて、確認できた生成元情報を記録し、確認できない著作権者を推測して追加しない方針を明記しました。
- アプリ内の「開発者より」タブから第三者ライセンス本文を確認できるようにしました。

## ライセンス検査

- AndroidのGradle依存関係検査にLicensee 1.14.1を導入しました。
- 許可されていない、または判定できないAndroid依存ライセンスがある場合に検査が失敗するようにしました。
- Licenseeの依存関係レポートをAndroidビルド成果物に同梱する設定を追加しました。
- npmの本番依存と推移依存を調査する`license-report-recursive`を導入しました。
- `npm run licenses:check`でnpmとAndroidのライセンス検査をまとめて実行できるようにしました。

## ドキュメント

- 第三者ライセンス調査結果と利用者向けライセンス文書の場所をREADMEに追記しました。
- ライセンス検査コマンドとレポートの生成場所をREADMEに追記しました。
