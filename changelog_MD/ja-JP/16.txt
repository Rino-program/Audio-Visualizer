# v1.1.3 変更履歴

## Android・Capacitor基盤

- Capacitor CLI、Core、Androidを8.5.3へ更新しました。
- Androidの最小SDKを24、compile SDKとtarget SDKを36へ更新しました。
- Capacitor 8に合わせてAndroidX Activity、Core、Fragment、WebKitなどの依存バージョンを更新しました。
- AndroidビルドをJava 21で実行できるよう設定を整理しました。
- Node.js 22以上、JDK 21を必要なビルド環境として明記しました。
- Gradle wrapperの実行権限をGit上で設定しました。
- npm依存関係を更新し、`npm audit`の脆弱性を解消しました。

## ファイル取り込み

- Androidのフォルダー取り込みを専用のバックグラウンドExecutorで実行するようにしました。
- 大量のファイルを含むフォルダーを取り込んでも、共有タスクキューを長時間占有しないようにしました。
- Activityの再生成や破棄が発生しても、未配送の取り込み結果をアプリ内部に保存して復元できるようにしました。
- 取り込み結果をプレイリストへ保存した後に確認応答を行うことで、保存失敗時にファイル参照を失わないようにしました。
- 保留中の取り込み結果がある場合、新しい取り込みで上書きしないようにしました。
- 保留結果の保存に失敗した場合、今回の処理で作成したファイルだけを削除するようにしました。
- 取り込み済みファイルの削除時に、アプリの取り込みディレクトリ外へアクセスしないようにしました。
- 複数回の取り込みや削除操作が競合しないようにしました。

## 安全性・安定性

- プレイリスト、ストレージ一覧、マイクデバイス一覧のDOM生成を安全化しました。
- ユーザーが選択したファイル名やパスがHTMLとして解釈されないようにしました。
- 設定やプレイリストの保存失敗を検知し、設定画面を閉じずに通知するようにしました。
- 復元処理に失敗してもアプリの初期化を継続できるようにしました。
- Capacitor 8の`registerPlugin`を使用してネイティブプラグインを取得するようにしました。
- フォルダー選択プラグインのActivity結果コードを登録しました。

## CI・ドキュメント

- GitHub Actionsの権限を整理し、不要な権限を削減しました。
- PR Agent ActionをコミットSHAで固定しました。
- Androidのビルド手順、署名設定、未署名APKの扱いをREADMEに追記しました。
- `keystore.properties`の設定例と`storeFile`の基準ディレクトリをREADMEに追記しました。
- Android debug/release APKのビルド手順を整理しました。
