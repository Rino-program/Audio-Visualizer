# v1.1.4 更新日志

## 第三方许可证

- 整理 npm、Android/Gradle、字体和图片素材的第三方许可证信息。
- 明确区分应用本体的 MIT 许可证与第三方组件许可证。
- 将应用本体的 MIT 许可证正文附加到 APK 中。
- 随应用附带 MIT、Apache License 2.0、0BSD 和 SIL Open Font License 1.1 正文。
- 记录 Inter 和 Roboto Mono 的版权及字体许可证信息。
- 记录已确认的图片和图标来源信息，不推测未确认的版权所有者。
- 用户可以在应用的“开发者信息”标签中查看附带的第三方许可证正文。

## 许可证检查

- 添加 Licensee 1.14.1，用于检查 Android Gradle 依赖的许可证。
- 当 Android 依赖使用未允许或无法识别的许可证时，许可证检查会失败。
- 配置将 Licensee 依赖报告附加到 Android 构建产物中。
- 添加 `license-report-recursive`，用于检查生产环境 npm 依赖及其传递依赖。
- 添加 `npm run licenses:check`，用于同时运行 npm 和 Android 许可证检查。
