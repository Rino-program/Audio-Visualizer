# v1.1.5 更新日志

## 渲染

- 删除了“渲染模式（自动 / GPU 优先 / CPU）”设置。
- 实际渲染一直使用 Canvas2D，并不存在 GPU/CPU 切换功能。现在会如实显示“渲染后端：Canvas2D”。
- 将资源监视器中的“GPU / CPU”显示改为“Canvas2D”。
- 旧版本保存的渲染模式设置会在加载设置和预设时自动删除。

## 语言支持

- 新增韩语（ko-KR）支持，包括 UI、应用内消息、Fastlane 元数据和更新日志。
- 完善日语、英语、简体中文和韩语的 README 与 SECURITY 文档。

## 文档

- 将安全策略的支持版本更新为 v1.1.5 及以上。

## 其他

- 使用 Prettier 格式化全部代码。
