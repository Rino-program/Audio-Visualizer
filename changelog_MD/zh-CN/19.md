# v1.2.0 更新日志

## 渲染

- 在设置中新增“内部渲染分辨率”，可选择省电 (1.0x)、标准 (1.5x)、高画质 (2.0x)、最高 (2.5x) 和原生。
- 调整内部渲染分辨率时，会补偿线条粗细和粒子大小，使条形、波形与砂粒等外观大小保持不变。
- 现在会根据渲染负载自动调整内部渲染分辨率。在较慢的设备上最多可降至 0.6 倍，有余量时逐步恢复。
- 将发光改为从独立可视化图层生成的低分辨率泛光合成（不包含背景）。条形数量较多时也能清楚看到光晕，背景不会发白。
- 低帧率模式下也可以使用发光效果。

## 性能

- 仅在播放或使用麦克风输入时运行渲染循环，暂停时停止绘制。修改设置或跳转播放位置时只重绘所需的帧。
- 应用进入后台时完全停止渲染循环，返回时恢复。
- 播放期间停止顶部栏和操作面板的毛玻璃背景模糊，降低每帧合成开销。
- 设置画面的草稿修改不再触发不必要的重绘。
- 仅在波形模式下获取时间波形数据。
- 通过复用频谱缓冲区、预计算彩虹色（LUT）、抽稀波形采样点、批量绘制数字方块、复用圆形模式的变换矩阵等方式降低绘制开销。

## 播放

- 支持从设备音乐库（MediaStore）批量导入曲目。
- 读取标题、艺术家、专辑和专辑封面，并显示在播放界面和通知中。
- 新增前台服务以支持后台播放，并支持通知、锁屏和耳机媒体控制。
- 支持音频焦点，在其他应用开始播放时暂停。
- 保存上次播放的曲目和位置，下次启动时继续播放。
- 新增“保持屏幕常亮”设置。
- 根据需要请求通知（Android 13+）和音乐库权限。

## 设置

- 设置画面的更改现在作为草稿保存，只有按下“保存并关闭”时才会应用。未保存关闭时会丢弃更改。
- 有未保存更改时关闭会先确认是否丢弃。
- 语言、麦克风、均衡器、播放速度等设置也会在保存时统一应用。

## 修复

- 修复了降低内部渲染分辨率后条形和监视器条形显得更细、圆形模式的砂粒显得更大的问题。
- 修复了开启发光但强度为 0 时没有任何效果的问题；开启时会自动将强度设为 20。
- 修复了 FPS 选择“无限制 (MAX)”后，重新打开设置画面时显示为 60 FPS 的问题。
- 修复了 FFT 品质预设覆盖已保存的“条形数量”的问题。
- 设置画面打开期间，键盘快捷键不再更改设置。
- 修复设置标签页显示浏览器默认白色边框的问题。
- 修复 Glow 强度标签在修改后或重新打开设置时不更新的问题。
- 修复显示“全屏 (F)”但 F 键无效的问题，并在帮助中补充说明。
- 修复重新打开设置时保留上次滚动位置的问题。
- 修复横屏时设置画面过窄的问题，改为全屏显示。
- 修复 Android 返回键无法关闭设置或播放列表、导致应用退出的问题。
- 修复横屏时顶部栏纵向过高、模式选择单独换行的问题。
- 修复设置中“预设”和“存储”标签页不显示、无法打开颜色预设和已保存文件管理的问题。标签栏现在保持在一行，在窄屏上可横向滚动。
- 修复平板和宽屏上顶部、底部栏过高的问题；600px 以上改为单行布局，手机上的留白也已减少。
- 播放列表现在始终固定在顶部栏下方，并自动调整高度和位置，避免遮挡底部播放控制。
- 补全缺失的翻译键并移除硬编码日文，使四种语言显示相同的界面。
- 修复启动时重复加载翻译文件的问题。
- 改进麦克风错误判断，避免仅因错误信息包含“Permission”就显示为权限被拒绝。

## 其他

- 为内部渲染分辨率和未保存更改确认的 UI 文案添加了日语、英语、简体中文和韩语支持。
- 将 UI 显示切换按钮移至顶部栏，仅在 UI 隐藏时显示浮动的“显示 UI”按钮。
- 新增 Glow 强度（弱/中/强）和“显示 UI”的日语、英语、简体中文、韩语文案。
- 将版本显示统一为 v1.2.0（版本代码 19）。
- 新增“文字与界面大小”设置，可在 80%～130% 之间调整除可视化画面外的整个界面文字大小。
- 将视频的“显示/隐藏”和“显示模式”合并为一个设置，可选择“仅音频 / 窗口 / 背景”。
